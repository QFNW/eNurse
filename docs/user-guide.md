# 易护使用说明

本文面向使用 Android App 的**患者**与**护理人员**，说明注册登录、打卡、提醒设置、小组管理等日常操作。Web 后台管理不属于本文范围。

适用于 App 1.0.4 及以上版本。

## 1. 安装与登录

### 1.1 下载与安装

- 用手机浏览器打开 `https://bohack26.kdns.fr/apk/app-release.apk` 下载安装包
- 系统要求：Android 8.0 及以上
- 首次安装时如提示“禁止安装未知应用”，需在系统设置中允许浏览器或文件管理器安装应用

### 1.2 注册账号

1. 打开 App，在登录页点击“没有账号？注册”
2. 选择角色：**患者** 或 **护理人员**（注册后角色不可修改）
3. 填写姓名、用户名、邮箱和密码：
   - 用户名：3–20 位字母、数字或下划线
   - 密码：至少 8 位
4. 点击“获取验证码”，到邮箱查收验证码并填入
5. 提交注册，成功后自动登录对应界面

> 如果长时间收不到验证码，请检查垃圾邮件；仍未收到可联系管理员。

### 1.3 登录

- 支持使用**用户名**或**邮箱**登录
- 勾选“记住密码”后，下次可直接点击常用账号登录
- 忘记密码：App 暂不支持自助找回，请联系管理员在 Web 后台重置

## 2. 首次使用：权限设置

提醒功能依赖系统权限，建议首次登录后逐项确认：

1. **通知权限**：首次启动时的系统弹窗请选择“允许”，否则收不到提醒
2. **精确闹钟**（Android 12 及以上）：保存提醒策略时如出现“开启精确提醒”，点击“去开启”，并在系统设置中允许“闹钟和提醒”
3. **自启动与电池优化**：国产系统（小米、华为、OPPO、vivo 等）建议在系统设置中允许易护自启动，并将电池策略设为“不限制”，避免提醒被系统清理
4. 退出登录后本地闹钟与服务端轮询都会停止，不再收到提醒

## 3. 患者端操作指南

登录患者账号后，底部有两个标签页：**首页** 和 **我的**。

### 3.1 大便打卡

1. 在首页“备注（可选）”中填写备注
2. 点击蓝色大按钮“大便打卡”
3. 看到“✓ 打卡成功！”即完成记录

首页顶部会以红色大字显示未解决的警报。确认问题已处理后，点击“标记已处理 →”即可消除该警报。

无网络时仍可打卡，记录会暂存在手机本地，联网后自动同步到服务器。

### 3.2 大便日历

1. 首页点击快捷入口“大便日历”
2. 用 “◀” “▶” 切换月份
3. 有排便记录的日期会标红，点击日期查看当天记录时间与备注

### 3.3 用药管理

1. 首页点击“用药记录”进入用药管理页
2. 点击右上角“+”添加药品，填写药品名与剂量（可选）
3. 点击药品卡片上的铃铛图标设置提醒：
   - **固定时间**：填写每天的时刻，多个时间用英文逗号分隔，例如 `08:00,20:00`
   - **间隔**：按“每 N 小时”提醒
4. 需要服药时，点击对应药品的“打卡”，可填写备注后点击“确认打卡”
5. 不再需要的药品可在卡片上点击“删除”

### 3.4 大便提醒策略

1. 进入“我的”→“大便提醒”
2. 设置提醒间隔与提醒时间（默认 08:00）
3. 点击“保存设置”

间隔含义：

| 间隔 | 含义 |
| --- | --- |
| 1 天 | 每天提醒 |
| 2 天 | 有一天没有记录就提醒 |
| 3 天 | 连续两天没有记录就提醒 |
| N 天 | 连续 N-1 天没有记录就提醒 |

如果护理人员锁定了策略，页面会提示“策略已由护理人员锁定”，此时患者无法修改。

### 3.5 小组

- **加入小组**：“我的”→“加入小组”，输入护理人员提供的邀请码，点击“加入”
- 每个患者最多只能加入一个小组
- **查看与退出**：“我的”→“我的小组”，可查看小组邀请码与成员，也可以退出小组；退出后将无法查看该小组数据

### 3.6 个人中心

在“我的”页面可以：

- 修改姓名、修改密码
- 提交问题反馈
- 检查版本更新
- 退出登录
- 注销账号（**不可撤销**，会永久删除打卡记录、用药记录和个人设置）

## 4. 护理端操作指南

登录护理人员账号后，底部有两个标签页：**小组** 和 **我的**。

### 4.1 创建小组

1. 在“小组”页点击“+”
2. 填写小组名称并创建
3. 进入小组后点击邀请码旁的“复制”，将邀请码发给患者

### 4.2 加入小组成为管理员

1. 在“小组”页点击“加入小组为管理员”
2. 输入邀请码并提交
3. 小组创建人会在小组详情页的“待审批管理员”中看到申请，点击“✓ 通过”或“✗ 拒绝”

### 4.3 管理小组成员

进入小组详情页可以：

- 查看邀请码并复制
- 审批管理员申请
- 查看成员列表及各成员的未解决警报数量
- 点击“＋ 添加虚拟患者”，为没有账号的患者建档并代录数据
- 点击成员右侧“移除”将其移出小组（之后护理端无法再查看该成员数据）

### 4.4 查看与编辑成员策略

点击成员进入“成员详情”，页面分为“事件”和“策略”两个标签：

- **事件**：查看该成员的警报、大便记录与用药记录
- **策略**：查看和编辑大便提醒策略、用药排班，也可以点击“＋ 创建药品”新增用药
- **锁定**：点击“锁定”后，患者端和护理端都无法编辑该策略；再次点击“解锁”恢复编辑
- 编辑策略后，如系统未开启精确闹钟权限，会提示“开启精确提醒”

### 4.5 代打卡

在成员详情页展开“💉 代打卡”，可选择：

- “💩 代大便打卡”：代患者记录一次大便
- “💊 代用药打卡”：选择对应药品代为打卡

### 4.6 护理端个人中心

护理端“我的”页面同样支持修改姓名、修改密码、问题反馈、版本更新、退出登录和注销账号。

## 5. 提醒没有响？

按顺序检查：

1. App 是否仍处于登录状态（退出登录后不再提醒）
2. 系统是否允许易护发送通知
3. Android 12 及以上是否已开启“闹钟和提醒”权限
4. 是否关闭了易护的自启动、是否被电池优化限制
5. 手机是否处于静音或勿扰模式

如果只是时间上差几分钟，通常是精确闹钟权限未开启，按第 3 项处理即可。

## 6. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 收不到邮箱验证码 | 检查垃圾邮件；稍后重试；仍失败请联系管理员 |
| 忘记密码 | 联系管理员在 Web 后台重置 |
| 无法加入小组 | 确认邀请码正确；确认自己尚未加入其他小组 |
| 无法修改提醒策略 | 策略可能已被护理人员锁定，请联系护理人员解锁 |
| 打卡失败 | 检查网络；离线打卡会暂存本地，联网后自动同步 |
| 版本更新失败 | 确认网络正常，并允许 App 安装未知应用；也可从下载地址重新安装覆盖 |
| 更换手机后没有提醒 | 重新登录并确认通知、精确闹钟、自启动权限 |

## 7. 数据与账号说明

- 打卡记录、用药记录和提醒策略保存在服务器，卸载重装不会丢失
- 退出登录不会删除数据
- 注销账号会永久删除该账号的全部数据，操作不可撤销
- 患者加入小组后，该小组的护理人员可以查看其警报、打卡记录、策略和日历
